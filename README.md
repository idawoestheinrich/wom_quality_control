# wom_quality_control
This is a repository for the process and analysis of quality control measurements on WOMs for the SHiP SBT.

- This is the google docs for the [WOM documentation](https://docs.google.com/spreadsheets/d/10ww-aOiFALShiBhOhexhOHCj1qeKmhqHUmBwvUTQB8A/edit?pli=1&gid=0#gid=0) done during the preperation and coating of the WOMs
## Directory Structure

- data is stored in /eos/experiment/ship/dsbt/woms/wom_quality_control/data
